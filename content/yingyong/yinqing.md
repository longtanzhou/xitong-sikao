## 企业家只有两项工作

作者"化繁为简"：企业家的两项工作，一是**设计并维持推动企业发展的"成长引擎"**（阳），二是**及时预见、防范并解决发展中的各种问题**（阴）。引《周易·系辞上》："一阴一阳之谓道"。

圣吉之问："如果把组织想象成一艘船，企业家应是什么角色？"——领导者常被忽视的重要角色是**船的设计师**。领导的最高境界是老子的"无为而治"："功成事遂，百姓皆谓'我自然'"。

## 成长引擎的定义

成长引擎是由一系列相互影响的要素构成的**反馈回路**（闭合环路），是推动企业持续成长的机制；主要是一类**增强回路**——每运转一圈，每个要素被增强一次，引发下一次更大幅度的增强。

"可持续"指剔除无长期影响的行动（如政府补贴、短期广告）。成长的动力只能来自有支付意愿和支付能力的用户数量与消费水平的提升（德鲁克：企业的目的唯一正确有效的定义是"创造顾客"）。

## 九种常见的成长引擎

1. **营销拉动**：密集营销 → 品牌知名度 → 销量 → 收入利润 → 加大营销投入；可持续条件是获客成本低于客户带来的收入；
2. **口碑效应**：满意用户"口口相传" → 更大销量 → 更广传播；可信度高、影响力大、成本更低——但口碑是"双刃剑"，企业只能施加影响、不可直接控制；
3. **病毒式营销**：营销信息像病毒一样经社交网络快速扩散；关键是"病毒系数"（每个用户带来多少新用户），低于 0.1 不可持续，大于 1.0 呈指数级增长；
4. **网络效应**：用户越多，商品 / 服务对其他用户的价值越大；本质是增强回路，结果是"赢家通吃"（"只有第一，没有第二"）；
5. **研发驱动**：加大研发投入 → 更高质量 / 更受欢迎的产品 → 更多销量 → 更多收入利润 → 进一步加大研发；
6. **人才驱动**：重视培训 → 员工能力提升 → 销量增加 → 收入利润 → 加大培训投入；
7. **信息支撑**：善用 IT 成为成长引擎（沃尔玛案例：降本增效支撑"天天平价"，商业智能创新业务模式增收）；
8. **知识引擎**：知道得越多学得越快、表现越好；组织积累的知识 / 经验越多，学习越快、优势越大；
9. **愿景引领**：愿景与现状的差距激发变革热情（调节回路）；现状改变引发发展需求、愿景更清晰，形成"创造性张力"的增强回路。

## 设计成长引擎六步法

1. 列出关键利益相关者（识别核心目标客户）；
2. 定义企业对核心利益相关者的价值（找出差异化 / 成本领先的独特要素）；
3. 发现价值之间的连接（寻找使各方价值相互促进的措施）；
4. 集体研讨、用因果回路图绘制"成长引擎"草图（独特能力要素用方框标注）；
5. 预想可能遇到的"成长上限"（设预警信号，"凡事豫则立，不豫则废"）；
6. 检验优化确认、调整战略与商业模式：从**可模仿性 / 脆弱性 / 可迁移性**三维度测试，对接"核心竞争力"三标准。

## 重要声明

通用引擎只是参考框架，不能简单套用；真实的成长引擎往往是潜在的，需要用系统思考把它显性化。

## 书中案例

谷歌的多要素自我增强系统；Hotmail 的病毒传播（18 个月达 1200 万用户）；LinkedIn 七大驱动因素叠加；莲雾大王的"口碑 + 产能"双回路；以及反面教材——人民航空公司在成长上限面前降低标准，致使增强回路逆转。
